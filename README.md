# AbogadosLama.cl

Sitio web oficial de **Abogados Lama Estudio Jurídico** — Providencia, Santiago, Chile.

> "Prevenimos problemas legales para tu negocio y familia y te representamos judicialmente ante un problema que ya tengas."
> — Rossy Lama Osorio, Abogada

## Especialidades
- **Litigios Civiles:** Juicios ordinarios y ejecutivos ante Juzgado de Letras y Corte de Apelaciones.
- **Litigios Penales:** Juzgado de Garantía, Tribunal de Juicio Oral en lo Penal, Corte de Apelaciones y Corte Suprema.
- **Litigios Administrativos:** Tramitación ante organismos de la administración del Estado.

## Infraestructura
- **Frontend:** Single Page Application (SPA) — `index.html`
- **Backend:** Firebase Cloud Functions (Node.js 20)
- **Hosting:** Firebase Hosting → Cloudflare (migración pendiente)
- **AI Agent:** `intakeChatbot` endpoint powered by Gemini 2.5 Flash
